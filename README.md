# Netflix-Data-Science-Project
A data science project done during diploma
The purpose for this project is to gain experience in data analysis, data visualization, and machine learning.


Preresquites installation: Python, Pandas, NumPy, Matplotlib, Scikit-learn


This project has done task such as:
Analyzed Netflix titles and their distribution by continent, visualized data using bar charts, built a Decision Tree classification model and a Logistic Regression classification model. Evaluated model performance using accuracy, precision, recall, specificity, and confusion matrices.



This file can be used to view result or run the step-by-step process. This file contains python code, visualizations, and model evaluation.
